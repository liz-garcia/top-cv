TopCV is a web application for creating one-page ATS-friendly resumes.

## System Overview

- **Client:** Vite, React, Redux, JavaScript, Tailwind CSS
- **Client deployment:** Heroku, NodeJS, Express, NodeJS buildpack

The NodeJS server in this repository is only used to host our client code in Heroku. Our full application server is built separately on another repository with Java, SpringBoot, Gradle. Link to full Server here: <https://github.com/liz-garcia/top-cv-server>

- **Server:** Java, SpringBoot, Gradle
- **Server deployment:** Heroku, Gradle, Gradle buildpack


- **Database:** MongoDB, Mongoose
- **Deployment:** Heroku
- **AI Provider:** Gemini API
